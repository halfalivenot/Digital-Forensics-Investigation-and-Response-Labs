# Digital-Forensics-Investigation-and-Response-Labs
A compliation of my labs within Digital Forensics, Investigation, and Response, Fifth Edition (Jones &amp; Bartlett Learning)

## Labs
| Labs | Description | 
|-------|------------|
| <a href="labs/Lab01">Applying the Daubert Standard to Forensic Evidence </a>| In this lab, acting as a Digital Forensic Specialist, I was given a hard drive image take from a seized computer that is suspected evidence. My role was to review the search warrant, complete the CoC, then prepare the evidence in accordance with the Daubert Standard using a variety of forensic tools. |
| <a href="labs\Lab02">Recognizing the Use of Steganography in Forensic Evidence </a>| In this lab, I'm given a hard drive image take from a seized computer that is suspected evidence. My role was to detect steganography tools, detect the presence of steganographically concealed data in the image file, and extract the concealed data. |
