# Digital-Forensics-Investigation-and-Response-Labs
A compliation of my labs within Digital Forensics, Investigation, and Response, Fifth Edition (Jones &amp; Bartlett Learning)

## Labs
| Labs | Description | 
|-------|------------|
| <a href="labs/Lab01">Applying the Daubert Standard to Forensic Evidence </a>| In this lab, acting as a Digital Forensic Specialist, I was given a hard drive image take from a seized computer that is suspected evidence. My role was to review the search warrant, complete the CoC, then prepare the evidence in accordance with the Daubert Standard using a variety of forensic tools. |
| <a href="labs\Lab02">Recognizing the Use of Steganography in Forensic Evidence </a>| In this lab, I'm given a hard drive image take from a seized computer that is suspected evidence. My role was to detect steganography tools, detect the presence of steganographically concealed data in the image file, and extract the concealed data. |
| <a href="labs\Lab03">Recovering Deleted and Damaged Files </a>| In this lab, I'm in charge of using professional data recovery tools and techniques to recover deleted data from different operating systems and file systems. Deleted data might hold incriminating suspicious evidence. |
| <a href="labs\Lab04">Conducting an Incident Response Investigation </a>| In this lab, I simulate the Analysis step of the incident response process. Given a packet capture (PCAP) file and disk image of a compromised employee, I analyzed them for evidence and compiled my findings into an incident response report. |
| <a href="labs\Lab05">Conducting Forensics Investigations on Window Systems </a>| In this lab, I grew familiar with Windows forensic investigation techniques. I investigated and used various Window utilities to perform live analysis on a Windows Server 2019 system, delved into the Windows Registry, and analyzed a Windows drive image using Paraben's E3. |
